# LeonIT — ИИ-интервьюер: описание проекта

Решение кейса Napoleon IT «ИИ-интервьюер: видеоинтервью и оценка кандидатов».
Команда 9. Стенд: <https://89-23-117-80.sslip.io>, код: `MaximIgitov/leon_it`.

## Задача и решение

Рекрутер тратит часы на первичные созвоны, кандидаты ждут слотов, а нанимающий
менеджер получает пересказ. LeonIT заменяет первичное интервью асинхронным
видеоинтервью: рекрутер описывает вакансию, требования и вопросы, кандидат
проходит интервью по ссылке в удобное время, а система транскрибирует ответы и
готовит структурированное заключение — с баллами по рубрике компетенций,
дословными цитатами, сильными сторонами, зонами роста, рисками и
рекомендацией «подходит / не подходит / требуется дополнительная проверка».
Решение принимает человек: рекрутер и нанимающий менеджер видят видео,
транскрипт и заключение, оставляют заметки и фиксируют решение; кандидат
получает честную обратную связь для роста.

## Что умеет

**Для рекрутера.** Вакансии с требованиями, навыками и рубрикой компетенций
(веса, якорные уровни 1–4); вопросы с лимитами подготовки/ответа и числом
перезаписей; генерация и вычитка вопросов моделью; приглашения по ссылке (в том
числе списком); карточка кандидата с видео, перемоткой по цитатам, транскриптом,
заключением, заметками и решением; ранжирование кандидатов по вакансии; вкладка
«Письма»; дашборд: воронка, средний балл, время до результата, согласие решений
с рекомендацией ИИ. AI-ассистент в кабинете: создать вакансию, сгенерировать и
вычитать вопросы, сводка и ранжирование, приглашение кандидата — необратимые
действия только через подтверждение.

**Для нанимающего менеджера.** Доступ только к своим вакансиям (scope) или по
ссылке на конкретного кандидата (срок, продление, отзыв, аудит просмотров):
полная запись с регулировкой скорости, транскрипт, заключение, резюме, история
диалога, заметки, решение.

**Для кандидата.** Понятный лендинг, страница согласий (персональные данные,
политика конфиденциальности, версии документов фиксируются), проверка камеры
и микрофона с подсказками для всех популярных браузеров и ОС, тренировочный
вопрос, вопросы с озвучкой, запись по одному ответу, докачка при обрыве связи,
возврат по той же ссылке, работа с телефона; после интервью — письмо с
обратной связью по настройке вакансии; отписка от писем.

**Оценка.** Модель получает только транскрипты с заменёнными персональными
данными в секциях, помеченных как данные, а не инструкции (случайные маркеры
секций, обезвреживание разделителей); заключение — structured output с
цитатами, каждая цитата сверяется с транскриптом; балл и рекомендация считаются
детерминированно по рубрике и порогам; eval-контур с датасетом «транскрипты →
метка эксперта» и кейсами инъекций измеряет согласие с экспертом (цель ≥ 80 %).

**Интеграции и задел.** HH.ru: OAuth, импорт вакансий и откликов, настраиваемый
диалог с кандидатом (приветствие → удобный срок → ссылка на интервью) с
историей в карточке; Huntflow: передача кандидата и ссылки на отчёт; публичный
API с токенами по областям и документацией; заделы под ИИ-аватар интервьюера и
секцию кода с запуском; уточняющие вопросы по ходу интервью (настройка
вакансии).

## Технологии

FastAPI + SQLAlchemy 2 (async) + Alembic, PostgreSQL 16; Next.js 14, TypeScript,
Tailwind, shadcn/ui; очередь задач в БД и воркер; ffmpeg; OpenAI-совместимый
шлюз к моделям с конфигурацией на роль (AI Tunnel по умолчанию, STT/TTS/LLM);
Playwright e2e с фейковой камерой; docker compose + Caddy (HTTPS); CI на GitHub
Actions с self-hosted раннером на стенде. Подробнее — [ARCHITECTURE.md](ARCHITECTURE.md).

   эксплуатация — [RUNBOOK.md](RUNBOOK.md).

## Качество

Модульные и интеграционные тесты бэкенда на SQLite и PostgreSQL (сотни
сценариев: права по ролям, state machine, пайплайн под сбоями, оценка под
инъекциями, интеграции с фейками), тесты фронтенда, сквозной сценарий
кандидата на Playwright с фейковой камерой в CI, миграции проверяются на
чистой базе, ruff и типизация в каждом PR.
