# LeonIT — ИИ-интервьюер

Платформа асинхронного технического видеоинтервью с ИИ-оценкой кандидатов.
Рекрутер описывает вакансию и вопросы, кандидат проходит интервью по ссылке в
удобное время, система транскрибирует ответы и готовит структурированное
заключение для рекрутера и нанимающего менеджера.

Решение кейса Napoleon IT «ИИ-интервьюер: видеоинтервью и оценка кандидатов».

## Состав

| Каталог | Что внутри |
|---|---|
| `backend/` | FastAPI, SQLAlchemy 2, Alembic — API, фоновые задачи, шлюз к моделям |
| `frontend/` | Next.js 14, TypeScript, Tailwind, shadcn/ui — кабинет, комната интервью, лендинг |
| `e2e/` | Playwright — регрессионные сценарии |
| `deploy/` | docker compose, Caddy, скрипты выката |
| `docs/` | [план разработки](docs/ROADMAP.md), архитектура, runbook |
