# LeonIT — ИИ-интервьюер

Асинхронное видеоинтервью с ИИ-интервьюером и оценкой ответов по рубрике с
доказательствами. Рекрутер описывает вакансию и компетенции, кандидат в удобное
время проходит интервью по ссылке как разговор с виртуальным интервьюером, а
система расшифровывает ответы и готовит заключение: балл, рекомендацию
«подходит / не подходит / нужна проверка», сильные стороны, риски и что
проверить дальше. Каждое утверждение подкреплено дословной цитатой из ответа.
Решение принимает человек.

## Что умеет

**Рекрутеру.** Вакансия из «классического» текста, файла или через ассистента;
рубрика компетенций с весами и якорными уровнями 1–4 строится по базе знаний
компании (грейды, ценности, примеры); вопросы с привязкой к компетенциям и
ожидаемыми признаками ответа. Список кандидатов с баллом, рекомендацией,
уверенностью и числом подтверждённых цитат; карточка с видео, транскриптом и
перемоткой по цитатам; рейтинг, решение и заметки; ссылка нанимающему
менеджеру со сроком, отзывом и аудитом просмотров. Бот сам ведёт переписку с
откликнувшимся на hh.ru до выдачи ссылки на интервью; кандидат уходит в
Huntflow одной кнопкой. Ассистент в кабинете предлагает действия, необратимое
выполняет только после подтверждения.

**Кандидату.** Согласия с версией документа, проверка камеры и микрофона,
тренировочный вопрос в том же формате, что интервью, живой диалог: вопрос
задаёт видеоаватар или голос, пауза завершает ответ, следующий вопрос звучит
сам. Работает с телефона, при обрыве связи ответы докачиваются, по той же
ссылке можно вернуться. После интервью — письмо с обратной связью.

**Нанимающему менеджеру.** Только свои вакансии или конкретный кандидат по
ссылке: запись, транскрипт, заключение, история, заметки, решение.

## Как считается оценка

Модель ставит баллы 1–4 по компетенциям рубрики и обосновывает каждый цитатой;
вердикт считает формула, а не модель: взвешенное среднее по рубрике,
нормализованное в 0–100, и пороги 45 / 70. Единица по критичной компетенции,
пропущенная компетенция и низкая уверенность опускают результат до «нужна
проверка»; компетенция без транскриптов исключается из среднего. Модель
получает только обезличенный текст, транскрипт передаётся как данные в секциях
со случайными маркерами сеанса, каждая цитата сверяется с транскриптом,
попытки повлиять на оценку остаются видимыми и попадают в отчёт.

## Результаты

| Что | Значение |
|---|---|
| Согласие с экспертом на контрольном наборе (23 кейса) | 21 из 23 = 91 % при цели 80 % |
| С двумя реальными заключениями заказчика | 21 из 25 = 84 %; модель строже эксперта компании на один класс |
| Цитаты, найденные в транскрипте дословно | 398 из 402 |
| Устойчивость к инъекциям в ответах | 5 из 5, метка не сдвигается в пользу кандидата |
| Ошибки «подходит ↔ не подходит» | 0 у четырёх сравненных оценщиков |
| Себестоимость интервью (12 мин речи) | 47 ₽ в базовой конфигурации, 4–17 ₽ в дешёвых; интервью до часа — 124 ₽ |
| Время от завершения интервью до заключения | медиана 7 минут на стенде |

Контрольный набор и скрипт согласия: `backend/evals/` (`make eval`). Отчёты
прогонов, сравнение оценщиков и экономика по конфигурациям — в
[материалах сдачи](https://leon-it.tech/materials/).

## Архитектура

```
кандидат ──HTTPS──▶ frontend (TanStack Start) ──/api──▶ api (FastAPI) ──▶ PostgreSQL
                       │                               │      ▲
                       │  подписанные ссылки           │      │ очередь задач в БД
                       ▼                               ▼      │
                    /data/media ◀── worker ── ffmpeg ── модели (STT · LLM · TTS · аватар)
                                                        │
                                              hh.ru · Huntflow · HeyGen
```

Бэкенд — модульный монолит на FastAPI (SQLAlchemy 2 async, Alembic,
PostgreSQL 16) с очередью задач в базе; фронтенд — TanStack Start, React 19,
TypeScript, Tailwind CSS 4, HeroUI 3; модели — OpenAI-совместимый шлюз с
конфигурацией на роль (`evaluator`, `assistant`, `interviewer`, `stt`, `tts`)
и детерминированной заглушкой для тестов; аватар — HeyGen через общий
интерфейс провайдера; выкат — GitHub Actions → GHCR → self-hosted раннер,
Caddy с HTTPS. Подробно: [ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Локальный запуск

Нужны Python 3.12 с [uv](https://docs.astral.sh/uv/), Node 22, ffmpeg. Без
ключей моделей провайдер переключается на заглушку (`MODEL_PROVIDER=fake`):
сквозной сценарий работает, тесты не ходят в сеть.

```bash
cd backend
uv sync
uv run alembic upgrade head
uv run uvicorn leonit.main:app --reload        # http://localhost:8000
uv run python -m leonit.jobs.worker            # воркер фоновых задач, отдельный процесс
```

```bash
cd frontend
npm ci
npm run dev                                    # http://localhost:3000, /api проксируется на 8000
```

Демо-организация с вакансиями, кандидатами, заключениями и базой знаний
заводится одной командой: `uv run python -m leonit.demo.seed --password <пароль>`.
Переменные окружения, ключи моделей и интеграций — в
[RUNBOOK.md](docs/RUNBOOK.md) и [backend/README.md](backend/README.md).

## Проверки

В каждом PR: ruff, pytest на SQLite и PostgreSQL, миграции на чистой базе,
tsc, vitest, сборка фронтенда; на `main` дополнительно e2e с фейковой камерой.

```bash
cd backend && uv run ruff check . && uv run pytest     # 466 тестов
cd frontend && npm run typecheck && npm test           # 62 теста
cd e2e && npm test                                     # Playwright, поднимает бэкенд и фронтенд сам
```
