# LeonIT — фронтенд

Next.js 14 (App Router) + TypeScript + Tailwind + shadcn/ui. Кабинет рекрутера и
нанимающего менеджера, комната интервью для кандидата, лендинг.

## Запуск

```bash
npm install
cp .env.example .env.local   # адрес бэкенда
npm run dev                  # http://localhost:3000
```

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

## Устройство

```
src/
├── app/            маршруты: (app) — кабинет, остальное — публичные страницы
├── components/
│   ├── brand/      логотип LeonIT
│   ├── interview/  комната кандидата: проверка устройств, сцена интервьюера, редактор кода
│   ├── landing/    секции главной страницы
│   ├── layout/     оболочка кабинета, заголовки страниц
│   ├── reports/    карточка кандидата: плеер, заключение, блок кода
│   └── ui/         shadcn/ui-компоненты
├── hooks/
├── lib/api/        клиент к бэкенду
└── lib/site.ts     адрес сайта, контакт, список юридических документов
```

### Комната: аватар и секция кода

`components/interview/avatar-stage.tsx` — «сцена интервьюера»: видео аватара,
если бэкенд отдал `avatar.clip_url` (фиче-флаг `AVATAR_ENABLED`), иначе персона
«ИИ-интервьюер LeonIT» с индикатором речи, подписанным на `<audio>` озвучки
вопроса. `components/interview/code-editor.tsx` — редактор для вопросов
`kind=code` без внешних зависимостей: номера строк, Tab/Shift+Tab, счётчик байт
с лимитом от бэкенда, черновик в `localStorage` (ключ по токену и вопросу) и
автосохранение на сервер, кнопки «Отправить код» и «Запустить» (выключена с
подсказкой, пока раннер не настроен). Переход к следующему вопросу требует
отправленного кода; пояснение на камеру — по желанию. В карточке кандидата и
отчёте по ссылке код показывает `components/reports/code-submission.tsx`.

Тема: акцент Napoleon IT `#140AF0`, гарнитура Manrope, светлая и тёмная схемы
через CSS-переменные в `src/app/globals.css`.

## Лендинг и демо-видео

Главная (`src/app/page.tsx`) адресована кандидату, который получил ссылку на
интервью: что его ждёт, как проходит интервью (шаги совпадают с комнатой в
`app/i/[token]`), что подготовить, что происходит с записью, FAQ; рекрутерам
— вход и регистрация в шапке и блок «Рекрутерам». Секции — серверные
компоненты в `src/components/landing`, без клиентского JS; FAQ — на
`<details>`. Мобильная вёрстка первична, заголовки по порядку, есть
skip-link. `app/robots.ts` и `app/sitemap.ts` отдают правила индексации
(страницы `/i/`, `/r/`, `/join` закрыты) и карту сайта: главная и
`/legal/<slug>`.

Блок «Видеодемо» показывает `public/demo/interview-demo.mp4`, которого в
репозитории нет: ролик пишет Playwright-сценарий кандидата (`E2E_VIDEO=1`,
инструкция в `public/demo/README.md`). Наличие файла проверяется на сервере
при рендере (`fs.existsSync`, для статической главной — при сборке); без файла
рендерится заглушка «Демо появится после записи», постер плеера —
`public/demo/poster.svg`. Тест `components/landing/landing.test.tsx` рендерит
страницу через `react-dom/server` и проверяет секции, ссылки, порядок
заголовков и обе ветки блока с видео.
