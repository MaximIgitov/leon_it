# Leon illustrations

Seven original assets generated with the built-in `image_gen` tool on 2026-09-06. All are 1254 × 1254 PNG files with genuine alpha transparency, inspected visually and checked with `sips -g hasAlpha`.

| File | Use |
| --- | --- |
| `logo.png` | Green smiling speech bubble and orange sparkle; wordmark is rendered separately. |
| `mascot-leo.png` | Leo, curly brown hair, green hoodie, waving hello. |
| `mascot-mira.png` | Mira, brown bob, orange sweatshirt, holding a laptop. |
| `mascot-max.png` | Max, glasses, cream shirt, interview clipboard. |
| `mascot-celebrate.png` | Leo celebrating with raised arms. |
| `mascot-listen.png` | Mira listening with headphones. |
| `mascot-think.png` | Leo thinking, hand on chin. |

## Generation prompts

The final prompt set is in `prompts.json`. The images use an original rounded cartoon style with leaf green `#58b83e`, forest green `#347c35`, tangerine `#ff9d4d`, cocoa `#49372b`, cream `#f6efe3`, and warm skin colors. No existing brand characters were used as references.

Generated originals were copied into this directory without image manipulation; alpha is preserved. Earlier variants containing rendered checkerboard backgrounds were rejected and are not part of this directory. Runtime motion and wordmarks belong to the frontend.
