# История Napoleon IT

- 2011 — Павел Подкорытов, Павел Бежин и Руслан Ахтямов основали компанию в Челябинске и начали разрабатывать приложения для «ВКонтакте». Один из первых проектов — агрегатор радиостанций, через который можно было слушать все станции мира онлайн.
- 2012 — создана внутренняя школа мобильных разработчиков; команда делала приложения, которыми пользовались миллионы. По данным раздела контактов, компания работает по всей России с 2012 года.
- 2013 — создан Napoleon Publisher, конструктор приложений для СМИ. Позже он стал главной в России платформой для публикации мобильных интерактивных версий журналов: Cosmopolitan, Esquire, РБК, Elle, National Geographic и Harvard Business Review.
- 2014 — начаты образовательные курсы по востребованным направлениям ИТ: машинное обучение, проектирование взаимодействия с данными, управление продуктами.
- 2016 — ставка на большие данные и машинное обучение: первое коммерческое решение для крупного ритейлера на основе компьютерного зрения и интеллектуального ценообразования.
- 2020 — одними из первых в России запустили магистратуру по машинному обучению с ЧелГУ; совместно с МФТИ создали магистратуру «Индустриальная биоинформатика».
- 2022 — совместно с ИТМО запущена крупнейшая в Европе магистратура по искусственному интеллекту AI Talent Hub; сейчас это 700+ студентов и выпускников.
- 2023 — вместе с XPage и PeopleDo открыта ИТ-школа GIGASCHOOL.
- 2024 — создан Napoleon AI-Driven Replenishment, комплексное решение для автоматизации пополнения и распределения запасов в ритейле; начато внедрение для Группы «Лента».
- 2025 — запущено направление разработки на основе больших языковых моделей: продукты, где человек и ИИ работают как единая команда.
