# Технологический стек Napoleon IT

## Стек компании (страница карьеры)

- Бэкенд: Python, Java, PHP.
- Фронтенд: Vue.js, React.
- Разработка и эксплуатация (DevOps): Ansible, Terraform, Yandex.Cloud.
- Искусственный интеллект: LLM, агенты, RAG, распознавание речи (Voice Recognition).
- Компьютерное зрение: Object Detection, OCR, Transformers, VLM.
- Мобильная разработка: iOS и Android (компания входит в топ-15 мобильных разработчиков России по Рейтингу Рунета 2024).

## Стек по направлениям стажировки

- Бэкенд: Python, FastAPI, Django, Docker, PostgreSQL, Redis, Kubernetes, GitLab CI/CD, PHP.
- Наука о данных: Python (pandas, NumPy, scikit-learn), PyTorch, TensorFlow, MLflow, ClearML, SQL и NoSQL (PostgreSQL, Qdrant), Airflow, Prefect.
- Тестирование: функциональное (web и mobile), автоматизированное, нагрузочное, API-тестирование.
- Анализ данных: Python (pandas, NumPy, matplotlib), SQL (PostgreSQL, ClickHouse), Power BI, Tableau, Apache Spark.
- Клиентская часть: TypeScript, React, Vue, Webpack, Vite, Jest, React Testing Library.
- Аналитика: Jira, Confluence, Google Docs, Word, Excel, BPMN, UML.

## Что это значит для интервью

Для бэкенд-вакансий ключевые темы — Python и асинхронность, FastAPI или Django, PostgreSQL и Redis, Docker и Kubernetes, CI/CD в GitLab. Для ML- и Data Science-вакансий — PyTorch или TensorFlow, MLflow или ClearML, векторные базы (Qdrant), оркестрация пайплайнов (Airflow, Prefect), продуктовые задачи ритейла: прогнозирование спроса, ценообразование, компьютерное зрение для полки и цен, LLM-агенты и RAG. Для фронтенда — TypeScript, React или Vue, сборка и тесты.
